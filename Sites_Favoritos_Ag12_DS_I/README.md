# Sites Favoritos

Projeto de página web que reúne uma seleção de sites favoritos e seus respectivos links.

## Habilidades desenvolvidas

Este projeto permite praticar a estruturação de páginas com HTML, a organização de informações e a criação de links para acesso a outros sites. Também envolve o uso do Visual Studio Code para editar o código e de Git e GitHub para acompanhar e organizar o projeto.

## Objetivo do programa

O objetivo é apresentar sites favoritos de forma simples e organizada, facilitando sua consulta e acesso. A atividade também busca aplicar conceitos introdutórios de desenvolvimento web.

## Modo de uso e detalhes

O arquivo index pode ser aberto em qualquer navegador da web compatível com o html5. Os arquivos index e a pasta imagens deverão ser salvos no mesmo diretório para o correto funcionamento.
A explicação do funcionamento do código está descrito em comentários nas respectivas linhas.
