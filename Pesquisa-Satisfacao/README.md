# Objetivo do programa
<br>
<br>
Coletar as notas de satifação dos clientes da empresa TudoWeb com 50 entrevistados. 
Utilizando a linguagem Phyton e estrutura de repetição "for", "if", etc, para a contabilização e correta classificação das entrevistas de opnião da satisfação com a empres de marketing TudoWeb.
<br>
<br>

# Campos de entrada de dados e suas funções
<br>
<br>

**"Opinião"** - o usuário deverá escolher, entre as opções apresentadas, qual é a sua satisfação com a empresa TudoWeb.
As avaliações são: Excelente, Bom e Ruim.
<br>
<br>

# Processamento e saída de dados
<br>
<br>
**Processamento**: o programa recebe a nota de satisfação classifica conforme critérios estabelecidos
<br>
<br>
**Saída**: Contagem das avaliações válidas.
